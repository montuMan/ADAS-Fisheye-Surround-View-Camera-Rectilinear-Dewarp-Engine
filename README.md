# ADAS-Fisheye-Surround-View-Camera-Rectilinear-Dewarp-Engine
A self-contained, production-grade C++ prototype for converting fisheye (Surround View Camera) frames to rectilinear frames, targeting ARM-based ADAS SoCs (Cortex-A72). Implements the Kannala-Brandt polynomial fisheye distortion model with Newton-Raphson inversion.
