# ADAS-Fisheye-Surround-View-Camera-Rectilinear-Dewarp-Engine
A self-contained, production-grade C++ prototype for converting fisheye (Surround View Camera) frames to rectilinear frames, targeting ARM-based ADAS SoCs (Cortex-A72). Implements the Kannala-Brandt polynomial fisheye distortion model with Newton-Raphson inversion. All geometric transformation is pre-computed at startup into a Q15.16 fixed-point Look-Up Table (~7 MB BSS), making the real-time hot path purely integer arithmetic — zero heap allocation, zero floating-point per frame. Bilinear interpolation is performed via staged fixed-point multiply-shift. Full ARM NEON SIMD vectorisation opportunities are annotated throughout (estimated 3–4× speedup). Includes a benchmark harness that validates correctness and measures throughput (~263 fps scalar on x86-64 at O2, projected ~920 fps post-NEON on A72). No OpenCV, no Eigen, no external dependencies.
